arch-launcher

Lightweight and independent Minecraft launcher script with Tkinter graphical interface.
Легковесный и независимый скрипт-запускатор Minecraft с графическим интерфейсом Tkinter.
Open Source Platform: Unix/Linux Language: Python

About the Project

О проекте

arch-launcher is a fully open-source project built on KISS principles for Unix-like systems (Linux, macOS, BSD). It provides a clean, bloat-free tool to start the game without forced Microsoft account integration or tracking.

arch-launcher — это полностью открытый (Open Source) проект, созданный по принципу KISS для Unix-подобных систем (Linux, macOS, BSD). Он предоставляет чистую альтернативу без лишнего веса, убирая необходимость обязательной привязки Microsoft-аккаунта и слежки.

Key Features

Особенности архитектуры

  • Pure Python & Tkinter: Native graphical interface. The application uses very few resources and starts instantly.
  • Чистый Python и Tkinter: Родной графический интерфейс. Программа потребляет минимум ресурсов и запускается мгновенно.
  • Single-file structure: The project is distributed as a single .py script, making it simple to audit, modify on the fly, and extend.
  • Один исходный файл: Проект представляет собой один файл .py, который легко читать, изменять на лету и настраивать под себя.
  • KISS Concept: No pre-installed modloaders (Forge/Fabric) by default. The launcher leaves full control over game files and directory structures to the user.
  • KISS-концепт: Отсутствие предустановленных загрузчиков модов (Forge/Fabric) по умолчанию. Лаунчер оставляет пользователю полный контроль над файлами игры.

Quick Start

Быстрый старт

1. Install the required library for managing game files:

1. Установите официальную библиотеку для работы с файлами игры:

pip install minecraft-launcher-lib

2. Clone the repository to your computer:

2. Склонируйте репозиторий к себе на компьютер:

git clone https://github.com/raesv-crypto/arch-launcher

3. Navigate to the project directory and run the launcher:

3. Перейдите в папку проекта и запустите лаунчер:

cd arch-launcher
python arch_launcher.py
